# IETF / IRTF Drafts

This directory contains the published XML for two individual Internet-Drafts
discussed in PEARG and a template for additional use-case contributions.

| Draft | XML | Read online | Release |
| --- | --- | --- | --- |
| Fully Homomorphic Encryption Use Cases and Gap Analysis for Network Services | [XML](draft-li-pearg-fhe-use-cases-00.xml) | [Datatracker](https://datatracker.ietf.org/doc/draft-li-pearg-fhe-use-cases/) | [Release](https://github.com/lihjacky/Homomorphic-CatPrivacy/releases/tag/draft-li-pearg-fhe-use-cases-00) |
| Ciphertext-Based AI Inference Tool Design for the Model Context Protocol (MCP) | [XML](draft-li-pearg-ciphertext-inference-tool-mcp-00.xml) | [Datatracker](https://datatracker.ietf.org/doc/draft-li-pearg-ciphertext-inference-tool-mcp/) | [Release](https://github.com/lihjacky/Homomorphic-CatPrivacy/releases/tag/draft-li-pearg-ciphertext-inference-tool-mcp-00) |

Both XML files are unchanged publication snapshots. For ongoing edits, use the
root-level [FHE use-case source](../draft-li-pearg-fhe-use-cases.xml) or
[MCP source](../draft-li-pearg-ciphertext-inference-tool-mcp.xml).

Contributions from other companies and the wider community are welcome. Use the
[use-case template](templates/use-case-template.md) and submit an
[issue or pull request](https://github.com/lihjacky/Homomorphic-CatPrivacy/issues),
or discuss the proposal on the PEARG mailing list, `pearg@irtf.org`.
The repository's [contribution terms](../CONTRIBUTING.md) apply.
