# FHE Use Cases and Gap Analysis — initial publication

**Fully Homomorphic Encryption Use Cases and Gap Analysis for Network Services**
(`draft-li-pearg-fhe-use-cases-00`) was published on 15 October 2026 as an
individual contribution for discussion in PEARG.

This release adds the use-case analysis alongside the earlier MCP
ciphertext-inference draft. Contributions of additional use cases from other
companies and the wider community are welcome.

- [Published draft on Datatracker](https://datatracker.ietf.org/doc/draft-li-pearg-fhe-use-cases/)
- [Both drafts: XML, HTML, text, and contribution materials](https://github.com/lihjacky/Homomorphic-CatPrivacy/tree/main/draft%20IETF-IRTF)
- [Use-case template](https://github.com/lihjacky/Homomorphic-CatPrivacy/blob/main/draft%20IETF-IRTF/templates/use-case-template.md)
- [Editable use-case source](https://github.com/lihjacky/Homomorphic-CatPrivacy/blob/main/draft-li-pearg-fhe-use-cases.xml)
- [Earlier MCP release](https://github.com/lihjacky/Homomorphic-CatPrivacy/releases/tag/draft-li-pearg-ciphertext-inference-tool-mcp-00)

The versioned XML/HTML/TXT attachments are byte-identical to the corresponding
IETF archive files. The `drafts-IETF-IRTF-2026-10-16.zip` bundle contains both
drafts' published files, templates, and supporting repository materials.
`SHA256SUMS` records the attachment hashes. Publication does not imply
research-group adoption or consensus. No new IETF submission is made by this
GitHub release.
